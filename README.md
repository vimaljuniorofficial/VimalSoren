# Vimal Soren — Web Engineer Portfolio

An interactive 3D WebGL portfolio built with Three.js and React.

## Deploying to Vercel

This project is pre-configured for one-click deployment on [Vercel](https://vercel.com):

1. Push this repository to GitHub or import it into Vercel.
2. In Vercel Project Settings:
   - **Framework Preset**: `Other`
   - **Root Directory**: `./` (leave default)
   - **Build Command**: `npm run build` (or leave default)
   - **Output Directory**: `public` (already configured in `vercel.json`)
3. Click **Deploy**.

## Local Development

```bash
npm install
npm run dev
```

The application runs on `http://localhost:3000`.
